# Backend - EcoTrack Wert

## Como rodar

1. Copie `.env.example` para `.env` e ajuste os dados do SQL Server.
2. Rode os scripts em `database/scripts` na ordem:
   - `create_tables.sql`
   - `seed_admin.sql`
3. Instale dependências:

```bash
npm install
```

4. Rode localmente:

```bash
npm run dev
```
