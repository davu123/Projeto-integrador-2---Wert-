# Frontend - EcoTrack Wert

## Como rodar

1. Copie `.env.example` para `.env`.
2. Instale dependências:

```bash
npm install
```

3. Rode localmente:

```bash
npm run dev
```

## Telas incluídas

- Login
- Dashboard inicial
- Cadastro de equipamentos
- Listagem de equipamentos
- Modo claro/escuro
- Ajuste de fonte e alto contraste
