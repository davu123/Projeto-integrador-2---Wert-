# Entregas

Esta pasta concentra os registros das entregas avaliativas do projeto. Use esses documentos para identificar o que foi submetido, qual sprint originou a entrega, quais critérios foram atendidos e quais evidências sustentam a avaliação.

O modelo em branco fica em [`template-entrega.md`](template-entrega.md). Cada entrega submetida vive na **própria pasta**, com o registro preenchido (`README.md`) e o PDF.

Atualize um registro sempre que houver submissão parcial, revisão avaliativa, reapresentação ou consolidação de resultado relevante para a disciplina.
