---

## Convenção de cada etapa

Dentro de `NN-nome-da-etapa/`:

| Arquivo | Função |
|---|---|
| `README.md` | Capa da etapa: status, links MD/PDF, o que o grupo precisa decidir |
| `*.md` | Documento de conteúdo (leitura fácil + fonte para IA) |
| `pdf/` | Documento formal em PDF (o grupo exporta e coloca aqui) |

Status usados neste índice:

- `validado` — chancelado pelo grupo
- `em redação` — conteúdo proposto, etapa em andamento
- `não iniciado` — só o esqueleto
